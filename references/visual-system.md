# 活动邀请函视觉系统

面向手机纵向阅读、分享和报名。高级感来自标题层级、比例、留白与细节的一致；科技感来自清楚的数据结构、节制的几何和光线。各主题应有可识别的构图语法，而不只替换一组颜色。

## 共用骨架

所有主题由同一份结构与同一张样式表渲染，主题差异写在 `assets/invitation.css` 的 `[data-theme="…"]` 段落里。

- **首屏**：小标 → 主标题（逐行遮罩入场）→ 一句主张 → 主视觉（大数字 + 主题图形）→ 时间地点 → 强调句。主视觉约占首屏一半，正文不压在复杂图形上。
- **长页**：主视觉 → 为什么来 → 具体内容/赛道/奖项 → 日程与规则 → 报名。块随内容增减，不补写嘉宾与流程。
- **节奏**：大数字、开放文本、细线列表、时间线交替；每段对应一个信息目的。全页只用一种容器语法，不为每段加卡片。
- **收束**：报名区是唯一反色（或唯一高饱和）色带，之后只留一行极简署名。

排版参数：正文 14.5–15px、说明 12.5–13px、行高 1.75–1.95、左右边距 `clamp(24px, 6.4vw, 46px)`、模块间距 40–66px。标题 `clamp()` 随宽度收缩，数字统一 `tabular-nums`。字体只用四套系统栈：`--font-sans`（PingFang SC）、`--font-serif`（Songti SC）、`--font-mono`（等宽小标）、`--font-display`（拉丁数字）。不依赖联网字体。

材质：全页一层 5.5% 噪点（`body::before`，overlay 混合），细线用 `--line`，金属色只用 `--metal` 且不超过三处。深色主题靠 `radial-gradient` 光斑和 1px 网格建立空间，不用大面积发光。

设计令牌：每个主题输出 `--bg --ink --muted --accent --surface --line --metal --band --bandink --bandmuted --contrast --glass --accent-soft --accent-line`。新增主题只改这组值不够，必须同时写构图块。

## `harbor` · 海湾蓝金

**来源**：两份中山企业家赴港研修 H5 PDF。

- **构图**：衬线大数字悬在城市天际线之上，天际线由高低错落的细线楼体组成，并带一层远景与水面倒影；金色地平线横切画面，右侧一枚金色日轮。全页只有这一处城市，不在每个块重复铺景。
- **令牌**：纸蓝 `#EEF2F5`、深蓝墨 `#0F2B3D`、强调蓝 `#1B5B85`、柔金 `#A8854E`、深色带 `#0F2B3D`。
- **排版**：中文无衬线 500 字重标题，数字用宋体细笔；价值块上沿金线、数字用蓝色；奖项为金边浅蓝铭牌，金额用衬线。
- **内容变体**：研修日程在手机改为日期＋主题＋安排的纵向行。资料不全时省略嘉宾块。
- **动效**：标题逐行上升、天际线淡入、金线展开。

## `arcade` · 青绿创作室

**来源**：参考1的 WorkBuddy × 麦当劳创作招募。

- **构图**：奶油色终端窗口轻微倾斜（-1.1°）作为首屏装置，深绿屏幕里是命令、光标与活动编号；圆点网格与暖黄光晕在背后建立工作室氛围。
- **令牌**：底 `#ECEFE4`、深青墨 `#123C35`、强调绿 `#1A6B57`、浅绿面 `#E0E6D4`、暖金 `#A8873C`。
- **排版**：粗体短句标题；编号＋名称的展开行；奖励做虚线票根，规则做左侧绿边的便签，不做统一卡片。
- **内容变体**：参与方法用 `1 → 2 → 3` 流程，工具/技能用勾选项。终端文本只用中性占位词，不写具体城市或人数，避免把示例当事实。
- **动效**：光标闪烁、按钮按压、内容低幅错峰出现。

## `neon` · 极夜荧绿

**来源**：参考2的 AECL 创作赛事海报与说明长页。

- **构图**：近黑舞台，细环与刻度围住荧绿斜体大数字，扫描线覆盖整屏首屏；章节序号与细线贯穿，奖项按名次做成榜单。
- **令牌**：底 `#08100D`、面 `#111D18`、荧绿 `#C2F06F`、白 `#EDF3EE`、灰绿 `#94A89C`；报名带为整幅荧绿反色。
- **排版**：高反差标题、大号斜体数字、等宽字母小标、开放分栏。荧绿只用于数字与动作。
- **内容变体**：名次横排三等分；赛道为可展开编号行；规则独立成易扫读段落。
- **动效**：线条展开、内容上移 14px、数字淡入；不做频闪、扫屏与粒子。

## `midnight` · 曜石香槟

**来源**：参考3的 AIdol 创造营赛事资料。

- **构图**：居中对称的请柬式版式。菱形花饰、双层金线铭牌与同心金弧构成仪式感，数字以宋体居中嵌在铭牌里；右侧竖排 `INVITATION`。
- **令牌**：底 `#0E1520`、面 `#18212F`、香槟金 `#DCC08C`、白 `#F2EEE6`、灰蓝 `#9FA9BA`。
- **排版**：宽松的居中标题与说明；奖项用切角铭牌（`clip-path` 切 14px 角）；正文仍用开放列表。
- **内容变体**：阶段制赛事用纵向日期轴；大奖、资源支持与服务权益按重要程度递进。
- **动效**：金线展开、几何淡入一次；不用闪光、旋转奖杯或夸张透视。

## `prism` · 棱镜未来

**来源**：参考4的 Anker 首届黑客松挑战赛。

- **构图**：左对齐的光谱渐变数字，右下方细线三角与折射光束，光束从三角右侧出画。构图不对称，留出大量黑场。
- **令牌**：底 `#070C14`、面 `#111B28`、白 `#F2F6F9`、青 `#8FDCEA`、灰蓝 `#93A6B7`；渐变从青到淡紫到浅绿。
- **排版**：标题 450 字重、大留白；数字用极轻字重与 `background-clip:text` 光谱；细线只用 1px。
- **内容变体**：真实产品图可占独立一段；没有产品图时使用自包含几何，不冒用品牌素材。
- **动效**：光谱一次显现、图文块微位移、分隔线轻展开；纯 SVG/CSS 即可，不需 WebGL。

## `editorial` · 纸上共创

**来源**：参考5的 AGIBuilder Logo 共创资料。

- **构图**：超大衬线数字从左侧出血，右上压一张微微旋转的纸卡（含小标、衬线短句与金色印章），横线纸纹从背景透出；标题第二行主动缩进。
- **令牌**：纸 `#F6F4EE`、墨 `#23271F`、灰 `#6A7063`、强调绿 `#3F6B4F`、浅绿面 `#ECE9DC`、金 `#A08A63`；报名带为墨色反色，按钮用金。
- **排版**：标题与章节标题用宋体 400；价值块改为单列边注编号；规则用悬挂缩进而非方框；奖项用一条 2px 粗线做头部。
- **内容变体**：共创故事用短段落；参与方法用编号注释；引用块（`quote`）可与主题完美配合。
- **动效**：纸面短淡入、边线渐显；不模拟纸屑飘落。

## 动效与可用性参数

`motion: subtle` 入场 450–1000ms、位移与遮罩为主、相邻延迟 60–100ms；只动 `opacity / transform`，细线可 `scaleX`。首屏动画由 CSS 完成，滚动区由 `IntersectionObserver` 触发，每组最多错峰四项。

`prefers-reduced-motion: reduce` 与 `motion: none` 停止全部动画与平滑滚动，内容默认可见。表单错误/成功不单靠运动表达；按钮触控热区不小于 44px。

信封可选，保留开封仪式并支持直接查看；减少动态效果时跳过翻折。音乐与声音仅在用户需要且有素材时加入。

## 素材与事实边界

参考图传递构图、形状、文字层次和阅读节奏，不自动授权复用其中品牌素材、人物照片或活动事实。优先 HTML/CSS/SVG 表达抽象构图；活动图像使用用户提供的可用素材。没有可靠 Logo 时以合作方名称排字，不编造 Logo。主题内置的示例英文仅作中性装饰（`INVITATION`、`invitation.session`），不得写入具体城市、人数、金额等可被误读为事实的内容。
