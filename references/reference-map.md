## 统一提炼原则

1. 每主题保留一个最强识别点：城市天际线、终端、荧绿数字、香槟几何、光谱三角或白纸编辑排版。
2. 将海报大图文字还原为真实 HTML 文本，手机正文不依赖放大图片。
3. 内容决定结构：赛道用编号列表，奖项用名次条，日程用日期轴，价值用短句和数字，报名用明确行动区。
4. 复用阅读节奏，不复制原参考的固定页数和事实。两份 PDF 是同一主题的完整版/精简版；五组参考补齐轻松创作、竞技科技、专业赛事、产品未来和社区共创方向。
5. 原图与 PDF 总览不作为默认整图背景。活动使用自有素材，抽象纹理与几何用 CSS/SVG 表达。
